## 逐项复核

| 原规则或行为 | 依据及实际后果 | 处理 |
| --- | --- | --- |
| 初筛要求具体产品／技术新进展 | 非用户要求。陶哲轩报道的现成摘要已提到近期公开完整演讲，仍被当旧观点排除；标题信息缺失被误作正文没有 | 相关且可能有价值先留。只用已有输入能支持的负面理由淘汰；观点、新公开材料和讨论可以合格。淘汰也须附实际输入引文 |
| 默认每条 120–220 字、最多两段 | 实现选择的硬默认。投资消息事实足够却因无法凑到 120 字被替换 | 默认字数／段数限制全部设为 0（不限制）；篇幅随信息量。只有核心消息说不清才缺料；不因短、无背景、无观点退稿 |
| 单稿必须证明超出原文的新增贡献 | 全局审稿自行添加。事实、标题、表达已通过，却仍连续返修 | 讲清事件、选编和组织事实可以构成成稿。只因具体事实、理解、标题、表达或明确栏目要求退回；不要求新增事实／观点或覆盖全部素材细节 |
| 写作与审稿逐段重复原文证明改动 | 与合格出稿无直接对应，拉长输入输出 | 单稿按段号关联必要问题，可无改动说明；写作不再重复审稿事实清单。核心事实核对仍由独立审稿完成 |
| 初筛重复维度及标签 | 同一判断与引文多次输出 | 初筛保留结论、简短理由、看点、引文、未知项；维度为 null，标签为空。保留两路并发及会话复用 |
| 可选配图在审稿前准备全部来源图 | 非用户要求。上一期 16 份材料共发现 98 张候选图，包含来源文章自身整期汇总图；不是成稿放了 98 张 | 文字审定后再处理图；简报先判断必要性，无需要则不下载、不搜图。候选准备设数量、尝试数及时间边界，不能把素材图总数当正文图数 |
| 简报配图数量 | 最新用户明确要求：默认不放，确有必要时一个主题最多一张 | 栏目保存 essential 策略、每主题上限 1。按实际成稿顺序绑定消息和材料，禁止跨消息放图；项目封面单独使用，不插正文 |
| 单轮取材上限必须大于整期最多条数 | 与已实现的多轮补筛矛盾，会阻止保存合理栏目设置 | 删除该约束；每轮预算与整期目标分开，缺额由系统继续取候补、补筛或补采 |
| 单稿数量界面 50、后端 10 | 界面与后端约定矛盾 | 统一可配置范围 1–50；本轮验收配置为 1 |
| 结构校验失败不记录 usage | 模型已计量但状态漏记 | 回执用量和会话续接先保存，再校验结构；取消请求无完整回执时继续标未知 |
| 自动运行报失败后子任务可继续消耗 | 整轮结束不等于子任务结束 | 正常调度停止该轮尚未完成的本地任务，阻止旧批次重新自动入队；保留已完成稿与其他轮任务；平台未知结果仍由原有取消保护拦截 |

必要约束保留：消息身份与材料对应、事实不编造、不同事件不混写、合格消息数量符合栏目、当前文字版本独立审稿通过。不得因这些检查而任意追加“必须长文”“必须多来源”“必须配图”或把内部来源记录堆到正文。
