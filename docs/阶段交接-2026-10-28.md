## 2026-10-29 在公司继续

1. 确认公司电脑的操作系统、网络和 Python；本次实测为 Python 3.12.10，建议先使用 Python 3.12。命令声明支持 Python 3.9+，其他版本及目标电脑尚未实测。
2. 新克隆仓库并进入项目目录（以下命令需在有 Git 与 Python 的终端运行）：

   ```sh
   git clone https://github.com/lierwa/content-workbench.git
   cd content-workbench
   python -m workbench collect
   python -m workbench serve --host 127.0.0.1 --port 8765
   ```

   在本机浏览器打开 `http://127.0.0.1:8765/`。也可先启动服务，再点击网页“手动采集”。首次采集会创建本机 `data/workbench.sqlite3`；如该机器使用 `python3` 命令，按实际环境替换。来源失败看各源结果，不要把失败视为零条正常结果。
3. 在页面查看候选并采用、待定或排除；需要助手处理时在能访问该项目数据的 Codex 会话说“处理已选”。用户查看整理后的稿件，再独立确认。具体操作与风险边界见[本地工作台使用说明](本地工作台使用说明.md)。
4. 用户自行创建微信公众号与今日头条账号；之后分别核对登录、权限、格式和首次实际发布结果。定时时间、部署机器和历史来源另行确认后再实施。

需要迁移原电脑已有的候选及选择状态时，另行备份和安全传递 SQLite；不要将个人状态或运行快照放进 Git 仓库。
