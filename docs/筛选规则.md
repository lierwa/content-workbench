## 用户原文

八项原文为：观众想纠正你、看翻车、打假、站队、蹲后续、当军师、代入自己、证明自己。

来源：原《产品规划/06-设置.md》“账号与读者”。

## 既有释义

以下为原《产品规划/05-选题决策.md》“比较的依据：观众为什么会关注”中的释义，保留原文：

| 观众可能想 | 判断要看什么 |
| --- | --- |
| 纠正你 | 读者可能对某个具体表述提出纠正，材料中能指出易遗漏的事实或限定条件；不能把作者向读者科普纠错写成“观众想纠正你”，也不故意制造错误。 |
| 看翻车 | 有可核查的先前承诺或形象，与实际结果构成反差。 |
| 打假 | 某个具体说法与可核材料不一致，能说明各自来源。 |
| 站队 | 真实存在不同处境、利益或价值取舍，各方说法有出处。 |
| 蹲后续 | 已发生的事仍有明确未决问题或后续节点。 |
| 当军师 | 当事人面对具体困境，可以讨论方案及其约束。 |
| 代入自己 | 普通读者能识别相关经历、费用或风险。 |
| 证明自己 | 可核事实与读者已有经验或判断形成呼应或冲突。 |
