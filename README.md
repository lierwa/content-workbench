# 公众号与头条内容经营流程验证

本项目用于验证短频快的内容经营流程：自动化收集热点和素材，筛选候选交用户挑选，快速整理发布并用数据复盘。未来多个账号共用流程，各自维护人群、定位和筛选规则。

当前工作重点是取得真实的流程成果。文件夹名 `content-workbench` 仅作为项目标识，产品形态尚未确定。先使用文档、清单、现成工具和必要的小脚本；只有实际执行暴露出明确问题时，才决定是否需要专用软件或 Web 界面。

## 任务文档

[公众号与头条内容经营任务书](./docs/内容经营任务书.md)是后续执行的主文档，包含目标、交付物、账号定位研究、素材来源验证、筛选与人工参与、发布验收、效果记录、任务顺序和工具投入条件。

明天继续操作请先看[2026-10-28 阶段交接](./docs/阶段交接-2026-10-28.md)和[本地工作台使用说明](./docs/本地工作台使用说明.md)。

## 执行约束

- 首批平台为微信公众号、今日头条；用户已选首个账号方向为[热点集合](./accounts/首个账号.md)。
- 重视内容的吸引力、代入感、讨论性、趣味和观看感受，不预设必须做知识或实用内容。
- 不安装 Docker，不依赖额外付费 API，不以 AI 自动撰写长文作为流程前提。
- 用户参与每天最多1小时；两个平台目前均无账号，也没有可持续的一手素材。
- 自动发布是后续需要实证的目标；人工发布、保存草稿与自动发布分别记录。
- 账号定位、素材来源和工具选择均由真实样本与执行结果支持。
