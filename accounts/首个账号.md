# 首个账号：热点集合

更新：2026-11-01。账号方向沿用用户选择；当前方案见 [内容经营任务书](../docs/内容经营任务书.md)。

## 账号与栏目线

“热点集合”是账号方向，不意味着每篇都把不同题材混在一起。一个账号可以承载多条栏目线；平台账号与栏目配置分开，具体发表到哪里由运行安排决定。

| 栏目用途 | 处理方式 |
| --- | --- |
| 当前热点单篇 | 由热点精选线承接现有集中三筛，寻找具体看点、参与空间和可写角度 |
| 同主题新闻集合 | 先限定来源、题材和本期范围，再选消息、压缩与编排 |
| 娱乐等其他方向 | 单独建立栏目线，保留自己的来源与选稿要求；当前只是配置示例 |

集合与单篇可共用线索及材料，各自保存判断和作品使用记录。不同栏目不得因共用池而混用来源规则；一期集合仍须有一致的内容承诺。

## 执行边界

目标是持续采集、按栏目生产并逐步自动发帖。采集、筛选、出稿、发布按各自节奏运行，不把当前串行批次作为长期限制。

基本采集只保存列表已有信息。热点精选线二筛后读正文；集合线选编后对入选消息取材核实，各自出稿。来源是否值得接入按本线内容供给与实际效果判断，清单见 [来源清单](../sources/来源清单.md)。

首批平台仍是公众号与今日头条。过去“账号尚未创建”、计划在哪台电脑部署等文字已经过时；本次未刷新账号或登录状态，实际身份和权限在获准的平台任务中回读。历史草稿不等于当前授权发布或自动发布已验收。

用户参与以每天最多一小时为既有目标，不能因此把所有重复劳动永久留给用户。持续供给、各栏目的读者反馈、实际耗时与收益仍需真实结果，文档和来源可读不能代替这些证据。
