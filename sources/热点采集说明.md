# 公开热点采集说明

本文引用的 `runs/` 原始证据仅保存在本机，不随仓库提交；外部读者可参考文中来源链接和结果摘要。

本轮使用今日头条公开热榜接口 https://www.toutiao.com/hot-event/hot-board/?origin=toutiao_pc ，无需登录，使用 Python 标准库；不安装依赖、不发布、不设置定时任务。运行命令：`python scripts/collect_hot_candidates.py`。脚本单次请求超时12秒，保存完整响应、采样时间、源顺序、原始热度、标题去重键和错误；默认选当次原始返回顺序前10个不同标题，只是未经筛选的线索，不自动抓正文或生成角度。各次时间戳文件独立保存；无额外账号或付费API。

本轮查看全榜后人工选10个话题ID，用 `--ids` 复采，不代表自动选题；人工再补三篇可读报道与加工角度，见 [候选](../runs/2026-10-27/234731_469951_候选人工复核.md)。[首错记录](../runs/2026-10-27/234530_568465_头条热榜.json) 因脚本错误预期 status=0 而失败，真实为 success；修正后两轮分别 0.313 秒、0.344 秒各10条。默认命令另在23:51:04实跑0.438秒取得10条；时间为脚本请求及处理耗时，不含人工筛选、找正文、写角度、用户参与、制作与发布。[小米短内容样例](../runs/2026-10-27-hot-sample.md)人工编辑170字，编辑段2分20秒，不含找源、审核、发布。

HotValue 是接口热度原值，计算口径不明，不是阅读量；source_order 只是 data 数组顺序，不假称实际名次。接口未给出可靠榜单更新时间、单条事件时间，不能仅凭采样时间断言事件新发生；手动阅读3篇正文，另外7条只有标题待核。持续可用性、平台账号、发布、定时运行均未验证。标题归一化仅做完全相同标题去重，不保证同事件不同标题合并。
